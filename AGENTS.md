
# Project Instructions

## Workflow
- Inspect relevant files before making changes.
- Prefer small, focused changes over large refactors.
- Reuse existing dependencies and project patterns.
- Don't read unrelated files unless needed.
- Run targeted tests for changes you make.
- Summarize files changed and tests run.

## Communication
- Ask before adding new dependencies.
- Explain your approach briefly before complex changes.
- Keep responses concise.
